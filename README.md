## 📁 Loyiha tuzilishi (qisqacha)

```
src/
├── layout/          # Main, Auth, Admin, Teacher, Game layoutlar
├── pages/           # Home, Games, Login/Register, Favorites, Admin panel
├── components/
│   ├── games/       # 30+ o'yin komponentlari (VR, quiz, mantiq, matematika...)
│   ├── main/        # Hero, HowItWorks, Trial, Comments, Games showcase
│   ├── header/      # Navigation header
│   └── footer/      # Footer
├── hooks/           # Game session, leaderboard, feedback, countdown...
├── apiClient/       # API mijozi (Gemini AI, subjects)
├── context/         # Global context
└── types/ utils/    # Tiplar va yordamchi funksiyalar
```

## ⚙️ O'rnatish va ishga tushirish

```bash
# 1. Reponi klonlash
git clone https://github.com/m-radjabova/gameverse_front.git
cd gameverse_front

# 2. Bog'liqliklarni o'rnatish
npm install

# 3. Muhit o'zgaruvchilari (.env) sozlash
#    .env faylini yarating va Firebase hamda boshqa API kalitlarini kiriting.
#    (Namuna uchun .env.example yaratilgan) — qo'shimcha: quyidagi kalitlar kerak:
#    VITE_FIREBASE_API_KEY, VITE_FIREBASE_AUTH_DOMAIN, VITE_GEMINI_API_KEY va h.k.

# 4. Dev serverni ishga tushirish
npm run dev
```

Platforma <b>http://localhost:5173</b> manzilida ochiladi ⚡
